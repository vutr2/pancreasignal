PancreaSignal

Urine-biomarker triage for pancreatic cancer (PDAC), inside an agent with a rule-based critic, cited guideline evidence and a human reviewer. Code, evaluation and limitations on GitHub.

Research prototype. Not a medical device. Synthetic cases only: do not enter real patient data.

Pipeline

intake → risk → critic → rag → human_review (pause) → report

  • intake validates the case. Every lab value needs a unit; unknown units are rejected, never guessed.
  • risk is a logistic regression on urine LYVE1, REG1B and TFF1 (each divided by urine creatinine), age and sex, trained on 590 patients from 4 hospitals (Debernardi et al., PLOS Medicine 2020, CC BY 4.0). Its output is a probability in case-control data, not a screening risk.
  • critic is a set of fixed rules, not an LLM, so every decision is explainable and tested. It withholds the estimate on a probable unit error or an unreadable case, and warns on out-of-range input, very dilute or concentrated urine, a raised CA19-9 during jaundice and a near-zero CA19-9.
  • rag turns each warning into a question for the guideline RAG (20 open-license articles, hybrid search, every sentence cited and checked by a second model call). The critic's questions are fixed, so their answers were computed once with that RAG and are shown from a snapshot.
  • human_review pauses until a person approves or rejects. Rejected reports are still written (audit trail).
  • report is English + Vietnamese, built from templates and the cited evidence, never free text from an LLM.

What runs on this page

This free version has no server. Pyodide runs the project's own Python in your browser: the same step functions, critic rules, unit checks and report templates as the server agent. The urine model runs as a pure-Python copy of the scikit-learn model (its coefficients in JSON), tested to give the same output. Nothing you type leaves this page.

The full version (in the repository) runs these steps as a LangGraph graph with a checkpointer and interrupt() for the human review, traces every node, and can answer free questions with the live RAG, which needs an API key and therefore a server.
